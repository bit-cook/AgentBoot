01 · INSTALL

One-command install#

bash
curl -fsSL https://boot.ide.pub/install.sh | sh
powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://boot.ide.pub/install.ps1'))"
bash
curl -fsSL https://bit-cook.github.io/AgentBoot/install.sh | sh
powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://bit-cook.github.io/AgentBoot/install.ps1'))"

The fallback source is published from the same tree as the primary entry (both /AgentBoot/ and /agentboot/ spellings work); the installer falls back across Worker → Pages → jsDelivr mirror → GitHub Release download sources, so any single domain going away still completes the install. If every custom domain expires, this domain-free entry still works: curl -fsSL https://github.com/bit-cook/AgentBoot/releases/latest/download/install.sh | sh.

Two commands after install:

agentboot

Console menu (install/uninstall agents, models, mirrors, offline builds) — Chinese UI, English switchable via agentboot lang en

ab

Built-in fallback agent — free model, zero config

The one-liner installs AgentBoot itself only — which third-party agents to install is always your choice in the menu.

04 · BUILT-IN

Built-in fallback agent (ab)#

Works when everything else fails — a Python standard-library core shipped with i18n and knowledge-base resources:

  • Tools: run commands (dangerous blocked/confirmed), read/write/edit files, search_files, fetch pages;
  • Offline Linux knowledge base: 9 topics — usage / operations / troubleshooting;
  • Session persistence (ab -c), streaming output, context auto-trimming.
ab — quick start
ab                                  # interactive (free model by default)
ab run "check disk usage"           # one-shot task
ab linux 查看端口占用                # query offline Linux knowledge base
ab doctor                           # environment check
ab bench                            # performance benchmark
ab model                            # provider manager

05 · OFFLINE

Offline packages#

Download a platform-and-Agent-specific verified pack from GitHub Releases. The pipeline runs on a self-hosted runner and verifies install, --version, and uninstall on Linux before uploading; Windows/macOS packs are built on demand via the release-platforms workflow. Build other Agents on their target platform with menu [7] or:

bash
python core/menu.py build-offline win-x64 claude-code,pi

Details: Installation Guide (EN) · 安装指南 (中文).

07 · UNINSTALL

Uninstall agents#

Open agentboot and choose [9] Uninstall Agents, or use the CLI:

bash
agentboot uninstall codex
agentboot uninstall codex,qwen-code       # batch uninstall
agentboot uninstall coco --purge          # also remove CoCo user data

AgentBoot records install ownership and will not remove an unrelated command merely because it has the same name. Normal uninstall removes the program, offline payload, and AgentBoot-owned shim while keeping model config, credentials, and sessions. --purge currently applies to CoCo and removes its user data as well; AgentBoot does not guess at other projects' data directories. Legacy v1.0.0 installs are removed automatically only when their AgentBoot ownership can be proven.

08 · BENCHMARK

Performance (measured via ab bench)#

ab bench measures KB cold/warm queries and first-token latency for a fresh TLS connection versus a reused connection on the current machine and provider. Results vary by network, model, and region and are not a fixed product guarantee.

10 · SECURITY

Security#

  1. The free model credentials are built in by design; remove PRESETS["agnes"]["api_key"] in core/agent.py if you fork;
  2. smart inspects every command-chain segment, blocks dangerous operations, and requires interactive confirmation for ordinary mutations; non-interactive runs never silently approve writes;
  3. safe permits read-only commands/tools only. Automation that intentionally mutates the machine must explicitly set confirm=always.
  4. Online tar/zip archives are fetched with same-origin .sha256 sidecars and verified before an atomic app-directory switch; failed upgrades preserve or restore the previous version.
