安装指南

安装、配置与故障排查——你需要知道的一切都在这里。

版本 v1.7.5 Linux · macOS · Windows 界面默认中文（切换：agentboot lang en）

AgentBoot 是一个极简、极速、开箱即用的 AI Agent 启动器：内置保底 Agent，其余 Agent（含 Cursor、OpenCode、Claude Code、Codex、FreeBuff 等）通过菜单自选安装。离线能力以注册表和目标平台构建验证为准；Cursor、Aider 与 FreeBuff 当前仅在线安装，OpenCode 使用固定官方 native binary 离线包，Hermes 必须在目标平台原生构建。

01 · ONLINE INSTALL

一键在线安装（推荐，机器需联网）#

Linux / macOS：

bash
curl -fsSL https://boot.ide.pub/install.sh | sh

Windows（PowerShell / CMD 二选一）：

powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://boot.ide.pub/install.ps1'))"
cmd
:: 或下载 install.bat 双击运行（GitHub 仓库根目录有该文件）

冗余入口（GitHub Pages，ide.pub 域名不可用或过期时使用；路径大小写均可，/AgentBoot/ 与 /agentboot/ 等价）：

bash
# Linux / macOS（路径大小写均可，/agentboot/ 同样有效）
curl -fsSL https://bit-cook.github.io/AgentBoot/install.sh | sh
powershell
# Windows PowerShell（把 install.sh 换成 install.ps1 即为 Windows 版）
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://bit-cook.github.io/AgentBoot/install.ps1'))"

终极兜底（GitHub Releases，不依赖任何自定义域名；ide.pub、osome.work 等域名全部过期时仍可用）：

bash
curl -fsSL https://github.com/bit-cook/AgentBoot/releases/latest/download/install.sh | sh
powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://github.com/bit-cook/AgentBoot/releases/latest/download/install.ps1'))"

维护提示：bit-cook.github.io 目前 301 跳转到自定义域名 osome.work；若该域名未来失效，在 GitHub 仓库 bit-cook.github.io 的 Settings → Pages 中移除自定义域名即可恢复 bit-cook.github.io 直出，上述入口全部自动生效。jsDelivr 镜像（cdn.jsdelivr.net/gh/bit-cook/AgentBoot@main/install.sh）不依赖任何 GitHub Pages 配置，国内通常更可达。

镜像兜底（安装脚本内部还会按 Worker → GitHub Pages → jsDelivr 镜像 → GitHub Release 顺序自动尝试下载安装包与 .sha256，无需手动操作；也可直连 GitHub main 获取最新开发版脚本）：

bash
# 直连 GitHub main（最新代码，未经发布验证）
curl -fsSL https://raw.githubusercontent.com/bit-cook/AgentBoot/main/install.sh | sh

安装完成后：

命令作用
agentboot打开中文控制台菜单（安装其他 Agent / 模型配置 / 镜像代理）
ab直接启动内置最小 Agent（默认 Groq qwen/qwen3.8-27b，免费模型自动备选）

Windows 新装命令需重新打开终端才会进入 PATH。在线安装器会从同一下载源获取 .sha256 并强制校验，完整新版本准备好后才原子切换；下载损坏或升级失败不会覆盖现有版本。

02 · OFFLINE INSTALL

一键离线安装（目标机器无网络 / 网络受限）#

离线安装只需三步：① 拿到离线包 → ② 拷贝到目标机解压 → ③ 运行离线安装脚本。全程不需要目标机器联网，也不需要安装任何解压软件（解压方案见下一节）。

第 1 步：获取离线安装包#

方式 A（推荐）：到 GitHub Releases 下载现成的离线包 → 选择：

AgentBoot-offline-v1.7.5-linux-x64-codex.tar.gz（Linux x64 · Codex）
AgentBoot-offline-v1.7.5-linux-x64-codex-sfx.sh（Linux x64 自解压单文件）
AgentBoot-offline-v1.7.5-linux-x64-opencode.tar.gz / -sfx.sh（Linux x64 · OpenCode）

Windows / macOS 离线包按需构建（release-platforms 工作流），不随每次发布上传；也可随时用菜单 [7] 或 build-offline win-x64 codex 自建。

方式 B（自建）：在有网的 Linux/macOS 或 Windows 机器上运行项目自带的构建脚本，自动从 npmmirror 镜像拉取全部 Agent 离线载荷并打包：

bash / powershell
# Linux / macOS（可自定义平台与 Agent 列表）
sh scripts/build-offline.sh
AGENTS="claude-code,codex" PLATFORMS="linux-x64,win-x64" sh scripts/build-offline.sh

# Windows（PowerShell）
powershell -File scripts\build-offline.ps1

第 2 步：解压离线包（目标机器没有解压软件也能做）#

离线包提供 4 种解压路径，按目标机器情况任选其一：

目标机器情况解压方法
Windows（任意版本）直接右键 ZIP → 全部解压缩。Windows 资源管理器自带 ZIP 支持，无需安装任何软件
Windows 10/11（命令行党，自建 win 包）系统自带 tar：tar -xf AgentBoot-offline-<版本>-win-x64-codex.zip
Linux x64系统自带 tar：tar -xzf AgentBoot-offline-v1.7.5-linux-x64-codex.tar.gz -C ~
Linux x64 极简环境用自解压单文件：sh AgentBoot-offline-v1.7.5-linux-x64-codex-sfx.sh

自解压包 *-sfx.sh 本身就是一个 shell 脚本 + 内嵌 base64 数据，sh xxx-sfx.sh 即自动解压并直接进入安装流程，非常适合只有最小化系统的服务器。

第 3 步：运行离线安装脚本#

Linux / macOS：

bash
cd ~/AgentBoot
sh install-offline.sh                    # 安装程序本体 + 打开控制台菜单（推荐）
sh install-offline.sh --all              # 一键安装全部支持离线的 Agent（不进菜单）
sh install-offline.sh claude-code qwen-code   # 只安装指定 Agent

Windows：

powershell
cd AgentBoot
powershell -NoProfile -ExecutionPolicy Bypass -File install-offline.ps1          # 安装 + 打开菜单
powershell -NoProfile -ExecutionPolicy Bypass -File install-offline.ps1 -All     # 全部 Agent
powershell -NoProfile -ExecutionPolicy Bypass -File install-offline.ps1 -Agents claude-code,qwen-code

也可以右键 install-offline.ps1 →「使用 PowerShell 运行」。若提示执行策略限制，用上面带 -ExecutionPolicy Bypass 的命令即可。

离线安装脚本做了什么（透明化）#

包内 PAYLOAD_SHA256SUMS.txt 会在目标机逐文件校验；任一载荷缺失或哈希不符都会停止安装。--all 只安装当前精简包 MANIFEST.txt 实际列出的 Agent。

  1. 校验 payloads/ 离线载荷完整性；
  2. 安装 AgentBoot 程序本体到 ~/.agentboot/app（Windows：%LOCALAPPDATA%\AgentBoot\app）；
  3. Python：Linux/macOS 使用系统自带 python3（绝大多数发行版自带）；Windows 若无 Python，自动从离线包部署便携版 Python（payloads/python/win-embed.zip，免管理员权限）；
  4. Node：系统没有 Node 时，自动从离线包部署便携 Node 22 运行时（payloads/node/<平台>/）；
  5. 将所选 Agent 的离线载荷直接落盘到 ~/.agentboot/agents/<id>/node_modules（不执行 npm），并生成 claude / codex / qwen 等命令的启动 shim；
  6. 把 ~/.local/bin（Windows：%LOCALAPPDATA%\AgentBoot\bin）注册进用户 PATH（幂等）；
  7. 内置 Agent ab 随装随用：联网机器默认 Groq（免费模型为自动备选）；纯离线机器在菜单 [4] 配置本地模型。

离线包内容结构#

AgentBoot/
AgentBoot/
├── install-offline.sh / install-offline.ps1   ← 离线一键安装脚本
├── MANIFEST.txt                                ← 包内清单（版本/平台/Agent 列表）
├── core/ agents/ tools/ scripts/ ...           ← 程序本体
└── payloads/
    ├── python/win-embed.zip                    ← Windows 便携 Python
    ├── node/<linux-x64|win-x64|darwin-arm64>/  ← 各平台便携 Node 22
    └── agents/<agent-id>/<平台>/node_modules/  ← 各 Agent 的完整离线依赖

离线安装常见问题#

现象处理
未找到 payloads/ 离线载荷目录脚本必须位于完整解压后的包根目录；或用 --payload <路径> 指定
Linux 上没有 python3apt install python3 / dnf install python3 / apk add python3 后重跑
装完命令找不到重开终端；或手动 export PATH="$HOME/.local/bin:$PATH"
某 Agent 提示平台载荷缺失该离线包构建时未包含此平台（用方式 B 自建，加 -Platforms 参数）
纯离线机器上 ab 连不上模型正常——Groq/Agnes 都需联网。菜单 [4] 配置本地模型（Ollama/LM Studio）后完全离线可用

03 · CUSTOM AGENT

自定义 Agent（安装注册表之外的任意 Agent）#

AgentBoot 支持用户添加自己想要的 Agent，不局限于内置注册表：

方式一：菜单向导（推荐）

agentboot → [2] 在线安装 Agent → 输入 + → 按向导选择安装方式（npm 包 / pip 包 / 安装脚本 URL）、填包名和命令名 → 保存后可立即安装，之后它一直出现在安装列表里（标 ★）。

方式二：命令行

bash
# npm 方式
python core/menu.py add-agent myagent npm @scope/some-agent some-cmd
# pip 方式
python core/menu.py add-agent myagent pip some-agent-pkg some-cmd
# 安装脚本方式（URL 直接执行）
python core/menu.py add-agent myagent script "https://example.com/install.sh" some-cmd
# 查看 / 删除
python core/menu.py add-agent --list
python core/menu.py add-agent --del myagent

自定义条目保存在 ~/.agentboot/custom-agents.json（Windows：%USERPROFILE%\.agentboot\custom-agents.json），升级或重装 AgentBoot 不会丢失；也可直接编辑该 JSON 文件批量管理。添加后用菜单 [2] 或 menu.py install <id> 安装，与其他 Agent 完全一致（国内网络同样自动走镜像）。

Hermes 的离线载荷包含平台相关的 Python venv，必须在对应目标平台构建。构建器检测到跨平台 Hermes 时会跳过该半成品载荷，避免生成无法运行的伪离线包；其他 npm Agent 仍支持跨平台打包。

04 · CUSTOM PACKAGE

自定义离线安装包（按需瘦身）#

官方 v1.3 Release 提供经过安装/启动/卸载验证的 Codex 与 OpenCode 精简包；其他 Agent 请在目标平台自行构建按需包：

方式一：菜单向导（推荐）

agentboot → [7] 构建自定义离线安装包 → 依次选择目标平台（如 win-x64）与要打入的 Agent（回车默认全选）→ 确认后自动完成构建，产物输出到 dist/。

方式二：命令行

bash
# 平台列表 与 Agent列表 均为逗号分隔
python core/menu.py build-offline win-x64 claude-code,pi
python core/menu.py build-offline linux-x64,darwin-arm64 coco,pi,hermes

按需包结构与 Release 精简包一致，目标机安装方式不变。未打入载荷的 Agent 会给出明确提示，可联网安装或在对应目标平台重新构建；实际体积取决于 Agent 及其平台运行时。

构建要求：构建机可联网（自动走国内镜像下载依赖）；构建 hermes 载荷需要本机 Git；构建产物按所选平台自动排除无关载荷与 CoCo 的 Windows 载荷。

提示：构建过程会在 dist/ 生成暂存目录与中间产物，可直接删除；同平台重复构建会覆盖同名文件。

05 · CHINA NETWORK

中国网络环境自适应#

AgentBoot 对国内复杂网络做了开箱即用的处理：

  • 自动判定：安装/运行时探测 registry.npmjs.org 连通性，不通则自动判定为中国大陆网络；
  • npm 镜像（可切换）：npmmirror（阿里）/ 腾讯云 / 华为云 / 官方源，安装 npm 类 Agent 自动使用所选源；
  • Node 运行时镜像：便携 Node 按序尝试 npmmirror → 华为云 → 腾讯云二进制镜像（nodejs.org 兜底）；
  • GitHub 加速（可切换）：gh-proxy.com / ghfast.top / ghproxy.net 自动探测选路，可固定指定或关闭直连；
  • pip 镜像：Aider 等 Python 工具自动使用清华 PyPI 镜像；
  • 多源下载容错：安装包只从项目控制的 boot.ide.pub → GitHub Pages → jsDelivr → GitHub Release 获取，并强制同源 SHA-256；
  • 代理支持：菜单 [5] 镜像与代理设置 可一键为 npm 与 AgentBoot 自身配置 HTTP 代理；
  • 手动切换：菜单 [5] 内可切换 npm 源与 GitHub 加速；命令行 agentboot mirror npm [源URL]、agentboot mirror gh [auto|off|前缀URL]；环境变量 AGENTBOOT_MIRROR=cn|off 强制镜像模式（默认自动）。

06 · MODEL PROVIDERS

模型配置（提供商管理器）#

ab 里输入 /model，或菜单 [4] 模型配置 —— 两者共用同一个模型提供商管理器：

ab /model — 提供商管理器
---- 模型提供商管理 ----
  [1] groq         qwen/qwen3.8-27b     (https://api.groq.com/openai/v1) ← 当前
  [2] agnes        agnes-2.5-flash      (https://apihub.agnes-ai.com/v1) ← 备选
  [3] ollama       qwen2.5:7b           (http://127.0.0.1:11434/v1)
  [4] lmstudio     local-model          (http://127.0.0.1:1234/v1)
  ...
  [s] 切换当前模型源   [a] 添加自定义提供商   [d] 删除自定义提供商
  [f] 设置故障切换顺序 [t] 测试当前模型        [0] 完成
  • Groq（默认）：内置预设（Base URL https://api.groq.com/openai/v1，模型 qwen/qwen3.8-27b，450 t/s 极速推理），首次运行自动生成配置、零设置直接对话；
  • 免费模型（备选）：内置预设（Base URL https://apihub.agnes-ai.com/v1，模型 agnes-2.5-flash），主源失败时自动切换；
  • 添加自定义提供商：任意 OpenAI 兼容接口（中转站 / vLLM / 私有部署），命名保存、随时切换删除；
  • 本地模型（完全离线）：内置 Ollama（11434）与 LM Studio（1234）预设；vLLM 可作为自定义 OpenAI 兼容提供商添加；
  • 故障切换：默认 groq → agnes；也可设置任意备用顺序（如 groq → ollama）；
  • Groq key 管理：内置默认 key（编码存放，防自动扫描）。用自己的 key：设环境变量 GROQ_API_KEY=gsk_...，或 /model → [a] 添加（提供商名填 groq）——显式配置优先于环境变量与内置 key。内置 key 被滥用时可在 Groq 控制台直接轮换；
  • 连通测试：一键验证当前模型。

配置保存在 ~/.agentboot/config.json，也可直接编辑。

07 · BUILT-IN AGENT

内置最小 Agent（ab）能力#

  • 零第三方依赖 Python 核心（仅标准库，随附 i18n 与知识库资源），启动即用；
  • 工具：执行命令（危险命令拦截/确认）、读写与精确编辑文件、目录列表、抓取网页；
  • 离线 Linux 知识库：内置 9 大主题（基础命令/系统信息/服务管理/网络/软件包/用户权限/磁盘/故障排查/终端技巧），问它 Linux 用法、让它操作 Linux、修简单问题（磁盘满、端口占用、服务起不来等）都可以；
  • 模型随时切换（/model），支持流式输出。

示例：

ab — 交互示例
ab                                  # 进入交互
你 › 查一下磁盘占用，满的话给出清理建议
你 › nginx 起不来怎么排查？
你 › /linux 查看端口占用

08 · UPGRADE & UNINSTALL

升级与卸载#

bash / cmd
# 升级：重跑在线一键安装即可覆盖更新（配置保留）
curl -fsSL https://boot.ide.pub/install.sh | sh

# 卸载单个 Agent（默认保留配置、认证与会话）
agentboot uninstall codex
agentboot uninstall codex,qwen-code

# 彻底清理 CoCo 程序和用户数据（不可恢复）
agentboot uninstall coco --purge

# 卸载 AgentBoot 本体（会删除 AgentBoot 自身配置）
rm -rf ~/.agentboot ~/.local/bin/agentboot ~/.local/bin/ab      # Linux/macOS
rmdir /s /q "%USERPROFILE%\.agentboot" & rmdir /s /q "%LOCALAPPDATA%\AgentBoot"   # Windows

POSIX 完全卸载后，还应删除 shell 配置中 # >>> agentboot >>> 到 # <<< agentboot <<< 的整段；Windows 在用户 Path 中删除 AgentBoot 的两个 bin 目录。

下载离线包后可先运行 sha256sum -c SHA256SUMS.txt --ignore-missing 验证外部归档；包内 PAYLOAD_SHA256SUMS.txt 用于解压后的逐文件二次校验。

也可在控制台选择菜单 [9] 卸载 Agent。AgentBoot 会记录安装归属，避免误删系统中碰巧同名的外部命令；默认保留 Agent 配置、认证信息与会话。--purge 目前只定义了 CoCo 的数据清理边界，其他 Agent 的数据目录不会被猜测删除。

09 · TROUBLESHOOTING

在线安装故障排查#

现象处理
curl 不存在用 wget -qO- https://boot.ide.pub/install.sh | sh，或先安装 curl
所有下载源失败用离线包安装；或给终端设置代理后重试
Windows 提示"禁止运行脚本"使用文档中带 -ExecutionPolicy Bypass 的命令
python3 自动安装失败手动安装后重跑脚本；或先只用其他 Agent（Node 类不依赖 Python）
装完 agentboot 找不到命令重开终端；或 source ~/.bashrc；Windows 重开终端窗口

10 · FAQ

FAQ（常见问答）#

Q哪些 Agent 装完就能用 免费模型？

Acodex 与 qwen-code 安装后由 AgentBoot 自动接线（config.toml / OPENAI_* 环境变量），开箱即用；opencode 写入 opencode.json；其余 Agent 按官方方式登录或配置（注册表 notes 有说明）。内置 ab 默认 Groq（失败自动切 Agnes 备选）。

Q为什么 codex 用 Agnes 预置时建议选 0.90.0？

A0.100+ 移除了 chat 协议，与 Agnes 预设不兼容。默认安装始终是最新版（官方登录不受影响）；要用 Agnes 预设请自选旧版：agentboot install codex@0.90.0。

Q瘦身包里没有我要的 Agent 怎么办？

A菜单 [7] 在目标平台重新构建并勾选它。离线安装遇到未打包的 Agent 会给出明确提示。

Q内置 ab 怎么用本地模型？

Aab → /model → 管理器选 ollama / lmstudio 预设，或 [a] 添加自定义提供商（任意 OpenAI 兼容接口）。完全离线场景用本地模型即可。

Q怎么验证性能？

Aab bench：输出知识库查询延迟（冷/热）、模型首字延迟（含 TLS 握手 vs 复用连接对比）。

Q离线包那么大，能再小吗？

A菜单 [7] 自选平台与 Agent 构建瘦身包（如 win-x64 仅 Pi ≈ 89MB）。Hermes 载荷含完整 Python 运行时（约 620MB），不需要就不要勾选。
