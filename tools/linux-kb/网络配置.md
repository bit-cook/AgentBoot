# Linux 网络配置与排查

## 查看网络状态
```bash
ip a                     # IP 地址（新）；旧命令 ifconfig
ip r                     # 路由表（默认网关看 default via）
ss -lntp                 # 监听中的 TCP 端口 + 进程（替代 netstat）
ss -s                    # 连接统计
ethtool eth0             # 网卡速率与状态
```

## 端口占用排查（最常见）
```bash
ss -lntp | grep :8080            # 谁在监听 8080
lsof -i :8080                    # 同上（需 lsof 包）
# 杀掉占用进程：kill <PID>；强杀：kill -9 <PID>
# 找到占用端口的进程名后也可：pkill -f "nginx: master"
```

## 连通性排查套路
```bash
1. ping 8.8.8.8          # 通 → IP 层 OK；不通 → 看路由/网卡
2. ping baidu.com        # 通 8.8.8.8 但域名不通 → DNS 问题
3. cat /etc/resolv.conf  # DNS 配置
4. curl -v telnet://1.2.3.4:443 或 curl -vI https://site   # 端口/HTTP 层
5. tracepath 8.8.8.8     # 路径追踪（或 traceroute）
6. ip r get 8.8.8.8      # 核实走的路由
```

## DNS 配置
```bash
cat /etc/resolv.conf
nameserver 223.5.5.5     # 阿里 DNS；114.114.114.114 / 8.8.8.8
# systemd 系统：
resolvectl status        # 或 systemd-resolve --status
# /etc/hosts 手动映射：1.2.3.4 api.example.com
```

## 防火墙
```bash
# firewalld（CentOS/RHEL）
firewall-cmd --state
firewall-cmd --list-all
firewall-cmd --permanent --add-port=8080/tcp && firewall-cmd --reload
# ufw（Ubuntu/Debian）
ufw status
ufw allow 8080/tcp
# iptables
iptables -L -n -v
iptables -I INPUT -p tcp --dport 8080 -j ACCEPT
```

## SSH
```bash
systemctl status sshd                    # 服务名可能是 ssh（Ubuntu）
ss -lntp | grep :22
cat /etc/ssh/sshd_config                 # Port / PermitRootLogin / PasswordAuthentication
# 改完配置：sshd -t 校验语法 → systemctl reload sshd
# 登录失败排查：/var/log/secure 或 journalctl -u ssh -n 50
ssh -v user@host                         # 客户端详细模式定位卡在哪一步
ssh-copy-id user@host                    # 免密登录
scp file user@host:/tmp/                 # 传文件；rsync -avz 更适合目录
```

## 代理
```bash
export http_proxy=http://127.0.0.1:7890 https_proxy=http://127.0.0.1:7890
# 写进 /etc/environment 或 ~/.bashrc 全局生效
# curl/wget/apt/git 分别也可单独配置代理
```
