# Linux 服务管理（systemd）

## systemctl 常用
```bash
systemctl status nginx       # 看状态（含最近几行日志）
systemctl start|stop|restart nginx
systemctl reload nginx       # 重载配置（不中断）
systemctl enable nginx       # 开机自启；--now 等于 enable+start
systemctl disable nginx      # 取消自启
systemctl list-units --type=service --state=running    # 正在运行的服务
systemctl list-unit-files --state=enabled              # 已设自启的服务
systemctl daemon-reload      # 改过 unit 文件后必须执行
systemctl cat nginx          # 查看 unit 文件内容
```

## 服务起不来排查套路
```bash
1. systemctl status nginx        # 看 Active: failed 及提示
2. journalctl -u nginx -n 50 --no-pager    # 完整报错
3. nginx -t                      # 配置文件语法检查（各类服务类似）
4. 端口被占？ss -lntp | grep 80
5. 权限问题？看 unit 里 User=，手动 sudo -u www 跑一遍启动命令
6. 路径问题？unit 里 ExecStart 一定用绝对路径
7. 改完 unit 文件 → systemctl daemon-reload → restart
```

## 自定义服务模板
```ini
# /etc/systemd/system/myapp.service
[Unit]
Description=My App
After=network.target

[Service]
Type=simple
User=app
WorkingDirectory=/opt/myapp
ExecStart=/opt/myapp/venv/bin/python server.py
Restart=always
RestartSec=3
Environment=PORT=8000

[Install]
WantedBy=multi-user.target
```
```bash
systemctl daemon-reload && systemctl enable --now myapp
```

## 定时任务
```bash
crontab -e               # 编辑当前用户
crontab -l               # 查看
# 分 时 日 月 周  命令（* 任意；*/5 每5分钟）
*/5 * * * * /opt/check.sh >> /var/log/check.log 2>&1
systemctl status crond   # 确认 cron 在跑（有的发行版叫 cron）
# 注意：cron 环境变量精简，脚本里用绝对路径；% 要转义为 \%
```

## 开关机与其他
```bash
shutdown -h now          # 立即关机（危险）
reboot                   # 重启（危险）
timedatectl set-timezone Asia/Shanghai   # 改时区
hostnamectl set-hostname web1            # 改主机名
```
