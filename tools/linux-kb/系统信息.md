# Linux 系统信息与性能

## 系统概览
```bash
uname -a             # 内核与架构
cat /etc/os-release  # 发行版版本
uptime               # 开机时长与负载
lscpu                # CPU 信息（核数、型号）
free -h              # 内存使用（available 才是真正可用）
df -h                # 各分区磁盘使用
df -i                # inode 使用（小文件耗尽 inode 也会写不进）
du -sh /var/*        # 各目录占用大小
du -h --max-depth=1 / | sort -rh | head    # 找最大目录
lsblk                # 块设备树
```

## 进程与负载
```bash
ps aux | grep nginx          # 查进程（忽略 grep 自己：grep [n]ginx）
top -bn1 | head -20          # 一次性快照（非交互）
htop                         # 交互式（更直观）
pidstat 1 5                  # 每 1 秒采样进程 CPU/IO（sysstat 包）
cat /proc/loadavg            # 负载：1/5/15 分钟；经验值：不超过 CPU 核数
```

## 内存排查
```bash
free -h                      # total/used/free/buff/cache/available
ps aux --sort=-%mem | head   # 内存占用 TOP 进程
dmesg | grep -i "out of memory"    # 是否发生过 OOM
cat /var/log/messages | grep -i oom    # 或 journalctl -k | grep -i oom
swapoff -a && swapon -a      # 重置 swap（确认内存足够时）
```

## CPU 排查
```bash
top -bn1 -o %CPU             # 按 CPU 排序
ps aux --sort=-%cpu | head   # CPU TOP 进程
pidstat -u 1                 # 每秒进程级 CPU
perf top                     # 热点函数（需 perf 包）
```

## 日志位置
```bash
journalctl -xe               # 系统最近日志（含报错上下文）
journalctl -u nginx -n 100   # 某服务最近 100 行
journalctl --since "1 hour ago"
/var/log/messages、/var/log/syslog、/var/log/secure（登录审计）
dmesg -T                     # 内核日志（带可读时间戳）
```
