# Linux 软件包管理

## Debian / Ubuntu（apt）
```bash
sudo apt update                  # 刷新索引（装包前先跑）
sudo apt install nginx           # 安装
sudo apt remove nginx            # 卸载（保留配置）；purge 连配置删
sudo apt upgrade                 # 升级全部
apt list --installed | grep php  # 已装列表
apt search redis                 # 搜索
apt show nginx                   # 包信息
apt-cache policy nginx           # 版本与候选源
```

## CentOS / RHEL / Fedora（dnf/yum）
```bash
sudo dnf install nginx
sudo dnf remove nginx
sudo dnf update
dnf list installed | grep php
dnf search redis
dnf provides "*/ifconfig"        # 查某个文件属于哪个包
```

## Arch（pacman）/ Alpine（apk）/ openSUSE（zypper）
```bash
sudo pacman -Syu nginx && pacman -R nginx
sudo apk add nginx && apk del nginx
sudo zypper install nginx
```

## macOS（brew）
```bash
brew install node && brew uninstall node && brew list
```

## 源与镜像（国内加速）
```bash
# apt 换源：备份后改 /etc/apt/sources.list（Ubuntu 24+ 在 /etc/apt/sources.list.d/ubuntu.sources）
#   阿里源 http://mirrors.aliyun.com/ubuntu  清华源 https://mirrors.tuna.tsinghua.edu.cn/ubuntu
# dnf 换源：/etc/yum.repos.d/*.repo 里 baseurl 换成 mirrors.aliyun.com/centos-stream
# pip：
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# npm：
npm config set registry https://registry.npmmirror.com
```

## npm / node
```bash
npm install -g pkg               # 全局装
npm install                      # 按当前 package.json 装
node -v && npm -v                # 版本
npm config get registry          # 看当前源
npm config set prefix ~/.npm-global   # 免 sudo 的全局目录（记得加 PATH）
```

## 查文件属于哪个包 / 包里有什么
```bash
dpkg -S /etc/nginx/nginx.conf    # Debian 系
rpm -qf /etc/nginx/nginx.conf    # RHEL 系
dpkg -L nginx                    # 包里有哪些文件
```
