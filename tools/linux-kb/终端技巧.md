# Linux 终端技巧与环境

## 环境变量
```bash
echo $PATH                       # 查看搜索路径
export PATH="$HOME/.local/bin:$PATH"    # 临时添加
# 永久：写入 ~/.bashrc 或 ~/.profile；source ~/.bashrc 立即生效
env | grep -i proxy              # 查看代理变量
unset http_proxy https_proxy     # 取消
```

## 任务控制
```bash
command &                        # 后台运行
jobs                             # 任务列表
fg %1 / bg %1                    # 调回前台/继续后台
nohup ./server > out.log 2>&1 &  # 退出终端仍运行
Ctrl+C 中断 · Ctrl+Z 暂停 · Ctrl+D EOF
```

## 常用快捷键
```bash
Ctrl+R  搜索历史命令（再按继续向前）
Ctrl+A / Ctrl+E   行首 / 行尾
Ctrl+U / Ctrl+K   删到行首 / 行尾
Ctrl+L  清屏（或 clear）
Tab 补全（双击列出候选）
```

## screen / tmux（断线不丢会话）
```bash
tmux new -s work                 # 新建会话
tmux a -t work                   # 重连；Ctrl+B D 分离
tmux ls                          # 列表
screen -S work / screen -r work  # screen 等价
```

## 文本编辑（服务器上最快路径）
```bash
vi /etc/nginx/nginx.conf
# 最小生存指令：i 进入编辑 · Esc 退出编辑 · :wq 保存退出 · :q! 不保存退出
# /keyword 搜索 · n 下一个 · dd 删除行 · u 撤销 · :set nu 显示行号
nano file.conf                   # 更直观（Ctrl+O 保存 Ctrl+X 退出）
sed -i 's/Port 22/Port 2222/' /etc/ssh/sshd_config   # 免编辑器改配置
```

## 开发常用
```bash
git status / pull / log --oneline -5 / diff
python3 -m venv venv && source venv/bin/activate    # python 虚拟环境
curl -X POST -H "Content-Type: application/json" -d '{"a":1}' http://127.0.0.1:8000/api
jq .field data.json              # JSON 解析（需安装）
nc -zv host 8080                 # 端口探测
openssl s_client -connect host:443 -brief   # TLS 证书查看
```

## 性能小抄
```bash
time <命令>                       # 耗时
strace -p <PID>                   # 系统调用跟踪
ltrace、lsof -p <PID>             # 库调用 / 打开的文件
watch -n1 "ss -s"                 # 周期执行
```
