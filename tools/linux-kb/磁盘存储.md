# Linux 磁盘与存储

## 查看磁盘
```bash
df -h                    # 文件系统使用率（排查"磁盘满"第一步）
df -i                    # inode 使用率（海量小文件会耗尽 inode）
lsblk                    # 物理盘与分区树
fdisk -l                 # 分区表详情
blkid                    # 分区 UUID 与文件系统类型
du -sh /var/log          # 目录实际占用
du -h --max-depth=1 /var | sort -rh | head    # 逐层找大目录
```

## "磁盘满了"处理套路
```bash
1. df -h                       # 找到满的分区
2. du -xh --max-depth=1 / | sort -rh | head    # 定位大目录（-x 不跨文件系统）
3. 常见元凶：
   /var/log        → journalctl --vacuum-size=100M 清日志；清大的 .log
   /var/lib/docker → docker system prune（删无用镜像/容器）
   /tmp            → find /tmp -mtime +7 -delete
   已删除但未释放：lsof | grep deleted   → 重启对应进程才真正释放
4. 确认：df -h
```

## 挂载与卸载
```bash
mount /dev/sdb1 /data            # 挂载
mount -o ro /dev/sdb1 /mnt       # 只读挂载
umount /data                     # 卸载（提示 busy：lsof +D /data 找占用）
# 开机自动挂载：写 /etc/fstab（写错会无法开机！先测试）
mount -a                         # fstab 校验（改完必须执行，无报错再重启）
# fstab 行格式：UUID=xxx  /data  ext4  defaults  0  2   （UUID 用 blkid 查）
```

## 分区与格式化（危险！会清数据）
```bash
fdisk /dev/sdb                   # 交互分区（g/n/p/w）
partprobe                        # 刷新内核分区表
mkfs.ext4 /dev/sdb1              # 格式化 ext4；mkfs.xfs /dev/sdb1
e2label /dev/sdb1 DATA           # 卷标
```

## LVM 常用
```bash
pvs / vgs / lvs                  # 查看物理卷/卷组/逻辑卷
lvextend -L +10G /dev/vg0/lv0    # 扩逻辑卷
resize2fs /dev/vg0/lv0           # ext4 扩文件系统；xfs_growfs /（xfs 用这个）
```

## swap
```bash
swapon --show                    # 查看
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
# 持久化：/etc/fstab 加  /swapfile none swap sw 0 0
```

## IO 排查
```bash
iostat -x 1                      # 每秒 IO（%util 高说明盘忙）
iotop -o                         # 哪个进程在读写
cat /proc/sys/vm/drop_caches     # sync; echo 3 > /proc/sys/vm/drop_caches 释放缓存（一般不需要）
```
