# Linux 基础命令（文件与文本）

## 文件与目录操作
```bash
ls -lah            # 列出文件（含隐藏、人类可读大小）
pwd                # 当前目录
cd /etc/nginx      # 切换目录；cd - 返回上一个目录
cp -a src dst      # 复制（保留权限/时间戳，适合目录）
mv old new         # 移动/重命名
rm -rf dir         # 递归删除（危险！先确认路径）
mkdir -p a/b/c     # 递归创建目录
ln -sf /opt/app/bin /usr/local/bin/app   # 建软链接
find /var -name "*.log" -mtime +7 -size +10M   # 按名/时间/大小找文件
find . -type f -exec grep -l "error" {} \;     # 找包含关键字的文件
```

## 文本查看
```bash
cat file                # 全文输出
less +F /var/log/syslog # 分页并跟踪（类似 tail -f，q 退出）
head -n 20 file         # 前 20 行
tail -n 50 file         # 后 50 行
tail -f /var/log/nginx/error.log    # 实时跟踪日志
wc -l file              # 统计行数
file some.bin           # 识别文件类型
```

## 文本处理三剑客
```bash
grep -rn "ERROR" /var/log/          # 递归搜文本，显示行号
grep -v "^#" conf | grep -v "^$"    # 去掉注释和空行
awk '{print $1, $3}' access.log     # 按列取字段（默认空格分隔）
awk -F: '$3>=1000{print $1}' /etc/passwd   # 指定分隔符：普通用户列表
sed -i 's/old/new/g' file.txt       # 原地替换（先去掉 -i 预览）
sed -n '10,20p' file                # 打印第 10-20 行
sort -n -k2 data.txt | head         # 按第2列数字排序
uniq -c                             # 相邻去重并计数（常配 sort）
cut -d: -f1 /etc/passwd             # 按冒号切第1列
```

## 压缩与打包
```bash
tar -czf out.tar.gz dir/        # 打包压缩
tar -xzf out.tar.gz             # 解压（系统自带 tar）
tar -xzf out.tar.gz -C /opt     # 解压到指定目录
tar -tf out.tar.gz              # 只看内容不解压
zip -r out.zip dir/             # zip 压缩（需 zip 包）
```

## 其他高频
```bash
which python3        # 命令在哪
history | grep ssh   # 查历史命令
xargs：find . -name "*.tmp" | xargs rm -f    # 把结果当参数
diff -u a.txt b.txt  # 对比文件差异
md5sum file          # 校验和
```
