AgentBoot

极简 · 极速 · 开箱即用的 AI Agent 启动器（Linux / macOS / Windows）。内置最小 Agent（默认 Agnes 免费模型），可从菜单一键安装 Claude Code、Codex、Qwen Code、OpenCode、CodeBuddy、MiMo Code、Cline 等。

一键在线安装

Linux / macOS

curl -fsSL https://bit-cook.github.io/AgentBoot/install.sh | sh

Windows（PowerShell）

powershell -NoProfile -ExecutionPolicy Bypass -Command "iex ((New-Object Net.WebClient).DownloadString('https://bit-cook.github.io/AgentBoot/install.ps1'))"

安装后

agentboot   # 控制台菜单（安装其他 Agent / 模型配置 / 镜像代理）
ab          # 内置最小 Agent（默认 Agnes 免费模型，开箱即用）

本页为 GitHub Pages 分发入口。安装脚本内部会自动按顺序尝试多个下载源 （Cloudflare boot.ide.pub → GitHub Pages → GitHub Releases → 国内加速镜像）； 中国大陆网络建议优先使用 boot.ide.pub。 GitHub 仓库
